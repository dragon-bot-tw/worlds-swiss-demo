# Proposal

## Why

2026 世界賽瑞士輪第四輪進行中，已結束的賽果與尚未開打的場次混在同一張對戰圖上。使用者要能沿用官方已打完的結果，自己指定還沒打的勝者，並立刻看到誰晉級、誰淘汰，而不必手打既有賽果，也不必計算八強對手。

## What Changes

- 新增一份寫死的 2026 瑞士輪賽程 JSON。製作時向官方賽程 API 抓一次最新資料，執行中的頁面不再同步。
- 新增一張全頁轉播式對戰圖：已完成場次鎖死，未完成場次可試算，第五輪在第四輪六場都有勝者後才配對。
- 點隊伍開局面板，可看戰績、晉級條件、50/50 走向機率；點一條走向會整條記住，之後配出的場次自動沿用。
- 新增「清除試算」，只清掉試算、保留官方賽果。
- 新增純 HTML、CSS、原生 JS 頁面，以及一個只負責送檔的 Node 靜態伺服器。

## Capabilities

### New Capabilities

- `swiss-snapshot`: 將官方賽程一次抓取後凍結成 JSON，並定義哪些場次已有勝者、哪些場次留空。
- `advance-trial`: 在凍結賽果之上試算晉級與淘汰，包含局面板、走向、固定配對、對手對調與清除試算。

### Modified Capabilities

- 無。

## Impact

- 專案目前只有標題與 OpenSpec 骨架，沒有既有應用程式碼。本變更新增頁面、樣式、原生腳本、靜態伺服器與賽程 JSON。
- 官方 `getSchedule` 只在產生 JSON 時使用一次。API key 不寫進檔案、頁面或伺服器。
- 不引入前端框架、打包工具或執行期對官方 API 的依賴。
- 八強抽籤與對手分布不在範圍內。
